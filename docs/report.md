**最终报告（2026-10-25）：逻辑简化后默认配置满足用户三项标准及官方 Tier 3。** 唯一官方要求为 [README-EN.md](../README-EN.md)。总面积 **29824.823 µm²**、频率 **346.414 MHz**、IPC 几何平均 **1.101955112**，同时满足面积 <36000、频率 >330、IPC >1.1。本轮删除 rename 的冗余空闲计数及访存响应合并中不可达的 store 缓冲，共减少 24 行。与简化前相比，面积增加约 208 µm²、频率下降约 5.72 MHz，25 个官方用例周期保持不变。完整依据见 [readability-2026-10-25.md](readability-2026-10-25.md) 与 [validation.md](validation.md)。

**参数敏感性**

默认：ISSUE_WIDTH=2、DECODE_WIDTH=2、ROB32、PRF64、IQ8、LDQ8、STQ16、I$ 2 KiB、D$ 16 KiB、ASSOC=1、WB_BYPASS=1、EARLY_REDIRECT=0、BTB64、BHT128。以下八变体实验来自本轮局部简化前的 352.132 MHz 版本，每组只修改所列参数，均通过官方正确性 19/19 和六项性能测试。本轮重跑默认配置，并对修改的模块做参数变体等价检查；未重跑八组完整 CPU 参数实验。只对当前默认配置给出最终面积/频率，不将不同配置的指标组合。

**架构探索与取舍**

1. 综合完整性先于分数。三处 package 结构体数组曾被原生 Yosys 错误展开；改为等宽位向量数组后，IFB、IQ 指令和写回 FIFO 得以完整展开。删除 keepdc 包装器并撤回旧 PPA。SRA/SRAI 的 signed/unsigned 混合表达式也已修正。
2. 面积/频率阶段通过缩小缓存和窗口、关闭同拍旁路，达到 28,683.282 µm² / 375.780 MHz，但 IPC 只有 0.896022。用户随后要求同时满足三项 Tier 3，故撤销过度牺牲 IPC 的部分：重新开启旁路，恢复 ROB32/STQ16，扩大 IQ/LDQ 至 8。
3. 原逻辑在这个窗口下的 IPC 达到 1.104763，但 BTB64 版本频率仅 250.122 MHz。提前前端恢复可取得更高 IPC，却形成更长组合路径，因此保留寄存恢复。BTB128 减为 64 不改变该阶段六项计数，节省约 1,995 µm²。
4. IQ 的变量索引串行轮转扫描改为并行资格掩码，内存年龄选择也并行化；保留发射次序、store 顺序、load 不能越过未发射老 store 的规则。单独采用它时频率为 283.186 MHz，尚未达标。
5. LSQ 的串行 guard/load 选择先试平衡树，再改为共享的并行年龄比较：较晚到达的资格不再经过多级年龄 key mux 和比较器。恢复拍统一暂停 load 调度，较老 load 下一拍继续，退休 store 不停顿。当时 BHT256 基线的 qsort 从 159,843 变为 159,846 周期，其余五项不变，IPC 为 1.104759629；当前 BHT128 配置的指标见本页开头。
6. 独立尝试过分配回绕位、原始写回唤醒、store 额外寄存级、更多 MSHR、缩小乘法延迟、加大 PRF，以及不复用同拍释放的 IQ 槽。它们未合入最终实现。特别是保守 IQ 分派使 IQ8 的 IPC 降至约 1.0934，低于门槛，不能用这种方式换取频率。
7. 简化代码时移除无使用者的分支计数、重复有效位和译码标志，删除从未接入的双指令融合接口；LSQ 删除不可达完成缓冲，保留 WAIT/SENT 两种状态及 store 转发寄存器。分开独立 BB 候选计算，去掉空端口；ALU/BRU 结果寄存器和 IQ 年龄减法保留原有实现。IFB/IQ 指令 payload 分别从 152/104 bits 缩为 140/100 bits；不改变指令延迟或发射策略。首版虽然面积降至 29,999.710 µm²，但频率为 299.415 MHz，未作为最终版本；环形比较候选的频率进一步降至 294.676 MHz，亦被撤回；最终保留原排序和结果寄存器写法，并将 BHT 从 256 项减为 128 项；重新测量同一配置的面积、频率、IPC 与完整回归，全部通过。

8. 用户要求在保留 Tier 3 的同时将频率提高到约 330 MHz。本轮只让 rename 从寄存后的 free_q 分配，提交/回收本拍释放的 tag 下一拍可用，切断同拍释放到优先分配器的依赖；得到 352.132 MHz、29616.839 µm²，默认六项性能周期与原版一致。IQ 年龄矩阵候选只有 301.35 MHz，未采用；没有合入其他流水线或发射策略变化。ROB64 变体的 IPC 从旧实现的 1.118425316 降至 1.114592867，说明较大窗口下延后复用有小幅代价；默认 ROB32 的 IPC 保持不变。参数变体、默认回归和实际网表均重新验证。

9. 本轮以可读性为目标，保留流水线和配置，仅删除两处冗余。rename 用分配前/分配后的位图判断两路是否有 tag，移除全量计数；memory_subsystem 直接仲裁 B/load 响应，删除复位后始终为零的 sp_v 及其载荷。模块等价检查、完整默认 RTL 回归、新综合和用户三项门槛均通过。硬件映射并不随源码行数单调改善，因此接受约 0.70% 的面积增加与约 1.62% 的频率下降，换取更直接的逻辑表达。

最终保留真实可切换的 ISSUE_WIDTH=1/2、DECODE_WIDTH=1/2、ROB/PRF/IQ 容量和 ASSOC=1/2。ROB 并行恢复、store 同拍捕获、MSHR/响应队列的恢复身份过滤等已有修复继续保留。
